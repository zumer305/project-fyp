🚨 Fix "nodemon is not recognized" Error

Complete Guide to Get Your Website Running

❌ Your Error

'nodemon' is not recognized as an internal or external command

This means: Node.js is NOT installed on your computer.

✅ The Solution

You need to install Node.js. It's free and takes about 5 minutes.

1 Download Node.js

  1. Click this link to open Node.js website:
👉 Open nodejs.org
  1. You'll see TWO green buttons
  2. Click the LEFT button that says "LTS" (Recommended)
  3. A file will download (about 30 MB)
  4. File name will be like: node-v20.10.0-x64.msi

2 Install Node.js

  1. Go to your Downloads folder
  2. Find the file you just downloaded
  3. Double-click it to start installation
  4. Click "Next" through all the screens
  5. Accept the license agreement
  6. Keep all default settings
  7. Click "Install" (may ask for admin password)
  8. Wait 2-3 minutes
  9. Click "Finish"

⚠️ VERY IMPORTANT!

RESTART YOUR COMPUTER after installation completes!

Without restart, Node.js won't work properly.

3 Verify Installation

After restarting your computer:

  1. Press Windows Key + R
  2. Type: cmd and press Enter
  3. In the black window that opens, type:
node --version

You should see something like: v20.10.0

Then type:

npm --version

You should see something like: 10.2.3

✅ If you see version numbers, Node.js is installed correctly!

4 Install Your Website Dependencies

Now install the packages your website needs:

  1. Open Command Prompt (cmd)
  2. Copy and paste this command:
cd "C:\Users\Abubakar Laptop\Desktop\project-fyp\project-fyp"

Press Enter, then run:

npm install

Wait 2-3 minutes for installation to complete.

5 Start Your Website!

Method 1: Using Command Line

npm run dev

Method 2: Using Batch File (Easier!)

  1. Go to folder: C:\Users\Abubakar Laptop\Desktop\project-fyp\project-fyp
  2. Find file: START_WEBSITE.bat
  3. Double-click it!

🎉 Success!

Your website will be available at:

http://localhost:3000

Open this link in your browser to see your beautiful website!
