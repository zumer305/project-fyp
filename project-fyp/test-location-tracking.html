🚀 Quick Start Guide

Step 1: Navigate to Your Groups

Go to: http://localhost:8080/groups

You'll see all your groups with two buttons for each:

💬 Open Chat 📍 See Location

Step 2: Open Location Map

Click the "See Location" button on any group card

You'll be redirected to: /groups/{groupId}/location-map

Step 3: Enable Location Sharing

Click the "Enable Sharing" button

Your browser will ask for location permission - click "Allow"

⚠️ Important: You must allow location access for this feature to work!

Step 4: View Member Locations

Once sharing is enabled:

  • Your location appears on the map with your initial
  • Other members who share their location will appear as colored markers
  • Click any marker to see member details
  • Use the member list below the map to focus on specific members

🎨 Map Features

  • Color-coded Markers: Each member has a unique color
  • Member Initials: Markers show the first letter of usernames
  • Info Popups: Click markers to see coordinates and last update time
  • Auto-fit Bounds: Map automatically zooms to show all members
  • Navigation Controls: Zoom in/out, rotate, fullscreen
  • Refresh Button: Floating button (bottom-right) to manually refresh

🔐 Privacy & Security

Your Privacy is Protected:
  • Location sharing is OFF by default
  • You must manually enable sharing for each session
  • Only group members can see your location
  • Stop sharing anytime by clicking "Stop Sharing"
  • Location data is not stored permanently

🧪 Testing Instructions

Test with Multiple Users

  1. Open your browser (Chrome recommended)
  2. Login with first user account
  3. Go to groups and enable location sharing
  4. Open an Incognito/Private window
  5. Login with a different user (must be in the same group)
  6. Enable location sharing on second account
  7. Both users should see each other on the map!

Test Location Simulation (For Testing)

Chrome DevTools Method:

  1. Open Chrome DevTools (F12)
  2. Press Ctrl+Shift+P (or Cmd+Shift+P on Mac)
  3. Type "sensor" and select "Show Sensors"
  4. In the Sensors tab, select a location or enter custom coordinates
  5. Now enable location sharing - it will use the simulated location!

🐛 Troubleshooting

Location Permission Denied

Solution:

  • Click the lock icon in browser address bar
  • Change Location permission to "Allow"
  • Refresh the page and try again

Map Not Loading

Check:

  • Internet connection (Mapbox requires online access)
  • Browser console for any errors (F12)
  • Mapbox access token is valid

Locations Not Showing

Verify:

  • You are a member of the group
  • Other members have enabled location sharing
  • Try clicking the refresh button
  • Check browser console for errors
