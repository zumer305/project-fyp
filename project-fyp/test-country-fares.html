How It Works

The system automatically detects the country based on the destination name stored in localStorage:

  • Azerbaijan: Baku, Ganja → Uses AZN (₼) rates
  • Kazakhstan: Almaty, Astana, Nur-Sultan → Uses KZT (₸) rates
  • Uzbekistan: Tashkent, Samarkand, Bukhara → Uses UZS (soʻm) rates
  • Kyrgyzstan: Bishkek, Osh → Uses KGS (с) rates
  • Tajikistan: Dushanbe → Uses TJS (ЅМ) rates
  • Turkmenistan: Ashgabat → Uses TMT (m) rates

Note: All prices are based on current December 2025 market rates from official taxi services and ride-sharing apps in each country.
